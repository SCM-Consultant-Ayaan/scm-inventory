# 바뀐 내용 (2026-11-03)

- B2B(F열) 출처: 수불부 출고(J) → `[예약 재고 관리]` 재고 분류 "출고 완료" 건
  - 제외: 업체명 큐텐(Qoo10) · 입고처 창고이동·시딩·코스맥스·뉴앤뉴
  - 날짜: 출고 예정일(D) → 비어 있으면 사용 예정일(C) (둘 다 날짜가 아니면 빠짐)
  - 상품명 → SKU 는 `[재고관리]` E→A 로 찾음 (이름이 다르면 빠짐)
  - 20% 규칙 그대로: 기준선(최근 14일 B2C 평균 × 2)까지 100%, 넘는 부분 20%
- L:N 열: 위 B2B 목록 (L2 한 칸 수식)
- A2: 수불부 (날짜, SKU) + B2B (날짜, SKU) 합친 목록 (수불부 날짜 범위 안만)
- K열: 수불부에 있는 행인지 — D열 B2C 14일 평균은 수불부 행만으로 계산 (B2B 때문에 추가된 행이 평균을 낮추지 않게)
