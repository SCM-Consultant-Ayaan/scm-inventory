# 로지킴 재고 통합 대시보드

**로지킴** 브랜드로 운영하는 SCM 재고 통합 대시보드입니다.

FBA·FBT·FBS 리포트와 3PL·자사창고 파일을 올리면 SKU별 창고 재고를 한눈에 확인하고 재발주 시점을 자동으로 계산합니다.

- **바로 사용:** https://scm-consultant-ayaan.github.io/scm-inventory/
- 주요 기능: 재고 대시보드 · 재발주 계산기 · 재고배분 · 재고수불부 연동 · 수요 입력(S&OP) · 발주 진행

별도 설치나 빌드 없이 `index.html` 한 파일로 동작합니다. 엑셀 처리 라이브러리(SheetJS)도 파일 안에 포함되어 있습니다.
